# 📊 Amazon Sales Dashboard 2024

This project is an interactive **Sales Dashboard** created in **Microsoft Excel**, designed to analyze and visualize Amazon's sales data across cities, states, and products in India for the year 2024.

## 🔍 Overview

The dashboard provides a comprehensive view of:

- 💰 **Total Sales**: ₹1,02,26,625
- 📦 **Total Units Sold**: 33,874
- 🏙️ **Number of Cities**: 23

## 📌 Key Visuals & Insights

- **City-wise Sales Trend**: Line graph showing sales performance across major Indian cities like Delhi, Mumbai, Pune, Bangalore, etc.
- **State-wise Sales Heatmap**: Geographic map showing sales intensity across Indian states.
- **Product-wise Units Sold**: Funnel chart indicating top-performing products based on unit sales.
- **Performance Indicators**: Doughnut charts to visually show sales, units, and city coverage performance.

## 🧰 Tools Used

- **Microsoft Excel**
  - Pivot Tables
  - Charts (Line, Doughnut, Funnel)
  - Power Map / Bing Map Integration
  - Formulas and Conditional Formatting
  - Interactive Dashboard Design

## 📈 Purpose

This dashboard helps in:

- Monitoring regional sales performance
- Identifying high- and low-performing products
- Making data-driven decisions based on city/state performance
